# Carousel Studio

Build swipeable website carousels and export 1080×1080 Instagram decks. The sample copy is written for [Lift The City Supplements](https://www.liftthecitysupplements.com/) — swap the handle and product names if you want another brand.

## What you get

- A reusable carousel primitive (arrows, dots, keyboard, swipe, optional autoplay)
- Homepage demos: hero Instagram slides, a multi-card product slider, and a quote carousel
- `/studio` — pick a template, edit slides, download one PNG or a ZIP of the whole deck

## Run it

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Studio lives at `/studio`.

```bash
npm test
npm run build
```

## Templates

- **Product drop** — isolate, creatine, pre-workout, then a shipping close
- **Education** — one idea, four slides
- **Community** — `@liftthecitysupplements`
- **Promo** — Toronto delivery and Canada-wide shipping
- **Blank deck** — two empty slides

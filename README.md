## Carousel Studio

[`carousel-studio/`](carousel-studio/) is an offline carousel maker for Instagram
and LinkedIn. Double-click `carousel-studio/index.html` to open it — no install,
no account, no internet connection needed.

- Write slides, preview the real swipe, export a ZIP of 1080 x 1350 PNGs for Instagram or a PDF for a LinkedIn document carousel
- Six slide layouts (cover, text, checklist, quote, big number, call to action), eight themes, four sizes
- Paste an outline to build a whole carousel at once

See [`carousel-studio/README.md`](carousel-studio/README.md) to get started and
[`carousel-studio/docs/posting-guide.md`](carousel-studio/docs/posting-guide.md)
for what each network expects.

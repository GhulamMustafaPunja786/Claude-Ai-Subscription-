## Key inventive features claimed

1. **Dual tripping mechanisms** — thermal (overload) + magnetic (short-circuit) in compact 2-module form factor  
2. **Arc fault detection and extinguishing** — arc runners, pre-chamber plates, arc chamber  
3. **Continuous internal self-test** with LED fault indication  
4. **IoT connectivity** — Wi-Fi / BLE to cloud platform  
5. **Integrated system** — device + cloud analytics + mobile app + smart-home APIs  
6. **Machine-learning energy recommendations** from historical telemetry

## Next steps before filing

1. Engage a **registered Canadian patent agent** (recommended; required for corporations in some cases).  
2. Conduct a **prior art search** (CIPO, USPTO, Espacenet) — especially AFCI and smart breaker patents.  
3. Complete placeholder fields in the Petition (address, phone, email).  
4. Convert SVG drawings to **PDF** at 300 DPI for CIPO e-filing.  
5. File online at https://www.ic.gc.ca/opic-cipo/cpd/eng/help/patents/e-filing.html  
6. Pay filing fee ($595.06 standard / $241.24 small entity as of Jan 2026).  
7. Request examination within 4 years of filing date.

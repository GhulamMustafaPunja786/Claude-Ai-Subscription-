🛡️ Golden Rule: Never edit the live theme first

Shopify lets you copy your theme (like photocopying a notebook). You make changes on the copy, preview them, then publish only when happy. That way the real website stays safe.

🧠 Big ideas in kid words

Meta Title = Store Sign

The blue link people see on Google. Must say what you sell + where (Toronto) + brand.

Meta Description = Window Poster

Short sentence under the blue link. Makes people click. Must match real offers ($150 / $250).

Schema = Robot Name Tags

Hidden labels that tell Google: “This is a store”, “This is a product”, “This is our address”.

Collections = Aisles

Too many aisles with the same snacks confuses Google. Keep clear main aisles.

✅ Do this / Don’t do that

✅ DO (safe)

  • Duplicate the theme first
  • Change SEO title/description in Shopify admin fields
  • Preview on the unpublished theme
  • Change 1 page type at a time
  • Write down what you changed

❌ DON’T (risky)

  • Edit the live published theme directly
  • Delete apps or big code chunks “to fix SEO”
  • Change product prices while testing SEO
  • Noindex important money pages by mistake
  • Publish schema without Rich Results Test

🧰 Safe implementation plan (zero drama)

  1. Make a backup theme
    Shopify Admin → Online Store → Themes → on the live theme click ⋯ → Duplicate. Rename copy to SEO Safe Copy — July 2026.
    Zero impact on live site
  2. Fix homepage title & description (admin only)
    Go to Online Store → Preferences (or homepage → Edit website SEO). Paste the new title/description below. Save.
    No code · No design change
  3. Fix top collection SEO fields
    Open each collection → scroll to Search engine listing → edit title + description. Start with only: Protein, Whey Protein, Creatine, Fat Burners, BCAAs, Contact.
    Text only · Customers won’t notice layout
  4. Add schema on the COPY theme only
    In the duplicated theme: Edit code → layout/theme.liquid (or Custom Liquid section in footer). Paste Organization + Store JSON-LD before </head> or in footer. Preview the copy theme URL. Test with Google Rich Results Test.
    Code on copy only Then publish
  5. Publish when checks pass
    If preview looks identical and Rich Results Test is green → Publish the copy theme. Keep the old theme as rollback for 2 weeks.
⏰ Best time to publish: Quiet hours (late evening). If anything looks weird, click the old theme → Publish to roll back in 10 seconds.

🏷️ Schema to add (robot name tags)

Add on theme COPY first

Put this inside a <script type="application/ld+json"> block in the theme copy:

{
  "@context": "https://schema.org",
  "@type": "Store",
  "name": "Lift The City Supplements",
  "url": "https://www.liftthecitysupplements.com/",
  "telephone": "+1-647-973-3793",
  "email": "ltc@liftthecitysupplements.com",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "50 Fort York Blvd",
    "addressLocality": "Toronto",
    "addressRegion": "ON",
    "postalCode": "M5V 4A6",
    "addressCountry": "CA"
  },
  "openingHoursSpecification": [{
    "@type": "OpeningHoursSpecification",
    "dayOfWeek": ["Monday","Tuesday","Wednesday","Thursday","Friday"],
    "opens": "11:00",
    "closes": "20:00"
  }]
}

Also add an Organization block (name, logo, same phone/email, social links). Full samples are in the technical audit file.

⚠️ Schema safety tip: Wrong schema rarely “breaks” the visible site, but bad JSON can break the script tag if you miss a comma. Always preview. If the page looks normal, customers are fine — schema is invisible.

📅 7-day easy schedule (no panic)

🧪 “Did I break anything?” 60-second check

  1. Open homepage on phone + computer — does it look the same?
  2. Add a product to cart — checkout still opens?
  3. Open a product page — price and “Add to cart” still work?
  4. View page source → search ld+json — schema present?
  5. If anything feels wrong → publish the old theme immediately.

# Hugging Face Spaces + Supabase (recommended: $0, no credit card)

This is the easiest completely free cloud host for n8n.

## 1. Create a free Supabase database

1. Sign up at [supabase.com](https://supabase.com) (GitHub login, no card).
2. Create a project. Wait until it is ready.
3. Open **Project Settings → Database**.
4. Copy the **connection pooling** host (often `*.pooler.supabase.com`), port **6543**, user, password, and database name `postgres`.
5. Turn on SSL if the dashboard offers it.

Optional keep-alive table (stops the free DB pausing after inactivity):

```sql
create table if not exists "keep-alive" (
  id bigint generated by default as identity primary key,
  name text,
  created_at timestamptz default now()
);
insert into "keep-alive"(name) values ('ping');
```

## 2. Create a Hugging Face Space

1. Sign up at [huggingface.co](https://huggingface.co) (no card).
2. **New Space**
   - SDK: **Docker**
   - Hardware: **CPU basic** (free)
   - Visibility: **Public** is fully free. n8n still has its own login.
3. Connect this GitHub repository, or paste the `Dockerfile` and `README.md` from this repo.

## 3. Space secrets (Settings → Variables and secrets)

**Secrets**

| Name | Value |
| --- | --- |
| `N8N_ENCRYPTION_KEY` | Output of `openssl rand -hex 32` — save this, never rotate it |
| `DB_POSTGRESDB_HOST` | Supabase pooler host |
| `DB_POSTGRESDB_PORT` | `6543` |
| `DB_POSTGRESDB_DATABASE` | `postgres` |
| `DB_POSTGRESDB_USER` | `postgres` (or the pooler user Supabase shows) |
| `DB_POSTGRESDB_PASSWORD` | Supabase DB password |
| `WHATSAPP_PHONE_NUMBER_ID` | From Meta Developer → WhatsApp → API setup |
| `WHATSAPP_ACCESS_TOKEN` | Permanent or temporary WhatsApp Cloud token |
| `WHATSAPP_NOTIFY_TO` | Your number, digits only, e.g. `923001234567` |

**Variables**

| Name | Value |
| --- | --- |
| `DB_TYPE` | `postgresdb` |
| `DB_POSTGRESDB_SSL_ENABLED` | `true` |
| `N8N_PORT` | `7860` |
| `N8N_PROTOCOL` | `https` |
| `N8N_HOST` | `YOURUSER-YOURSPACE.hf.space` |
| `N8N_EDITOR_BASE_URL` | `https://YOURUSER-YOURSPACE.hf.space` |
| `WEBHOOK_URL` | `https://YOURUSER-YOURSPACE.hf.space/` |
| `N8N_PROXY_HOPS` | `1` |
| `N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS` | `true` |
| `GENERIC_TIMEZONE` | `Asia/Karachi` |
| `TZ` | `Asia/Karachi` |
| `EXECUTIONS_DATA_PRUNE` | `true` |
| `EXECUTIONS_DATA_MAX_AGE` | `168` |
| `EXECUTIONS_DATA_SAVE_ON_SUCCESS` | `none` |
| `EXECUTIONS_DATA_SAVE_ON_ERROR` | `all` |

Rebuild the Space after saving.

## 4. First login

Open `https://YOURUSER-YOURSPACE.hf.space`, create the **owner account**, then import:

- `workflows/typeform-to-whatsapp.json`
- `workflows/keep-n8n-awake.json`

Activate both workflows. Copy the **Production** webhook URL from Typeform Webhook (`/webhook/typeform-lead`).

## 5. Keep it awake (free)

Free Spaces sleep after idle time. Internal n8n cron does **not** count as traffic.

Create a job at [cron-job.org](https://cron-job.org) (free, no card):

- URL: `https://YOURUSER-YOURSPACE.hf.space/healthz`
- Interval: every 10–15 minutes
- Enable it

Optional second job for the DB: a GET to your Supabase REST `keep-alive` table using the anon key.

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| Space 404 / never ready | Confirm `N8N_PORT=7860` and logs show `n8n ready on … port 7860` |
| DB `ENETUNREACH` on 5432 | Use **pooler** host and port **6543**, not the direct 5432 host |
| Saved credentials unlock fail | `N8N_ENCRYPTION_KEY` changed. Restore the original key |
| Webhooks hit the wrong host | `N8N_HOST`, `WEBHOOK_URL`, and `N8N_EDITOR_BASE_URL` must match the Space URL |
| WhatsApp 131030 / 131047 | Number not on the allowed test list, or you sent a session text without a template |

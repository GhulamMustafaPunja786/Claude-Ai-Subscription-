Carousels

A lightweight, dependency-free carousel component — arrows, dots, autoplay, swipe & keyboard support.

1. Hero carousel

Single slide per view, loops infinitely, autoplays every 4 seconds (pauses on hover). Try dragging with your mouse or swiping on touch.

Slide 01

Build once, use anywhere

Drop the component into any page — no frameworks, no build step, no dependencies.

Slide 02

Autoplay that respects users

Rotation pauses automatically on hover and keyboard focus.

Slide 03

Swipe & drag friendly

Works with touch gestures on mobile and mouse dragging on desktop.

Slide 04

Keyboard accessible

Focus the carousel and use the arrow keys to navigate.

2. Card carousel (multi-item)

Shows 1 card on mobile, 2 on tablet, 3 on desktop — configured with responsive breakpoints.

⚡

Fast

Pure CSS transforms with zero layout thrashing — buttery-smooth on any device.

📦

Zero dependencies

One small JS file and one CSS file. No npm install, no bundler required.

📱

Responsive

Configure how many slides show per breakpoint with a simple options object.

♿

Accessible

Keyboard navigation, ARIA labels on controls, and focus-aware autoplay.

🎨

Themeable

Plain CSS classes make it easy to restyle arrows, dots, and slides.

🔄

Looping

Optional infinite looping, or clamp at the ends with disabled arrows.
